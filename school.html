01

What is AWE?

AWE is a family of independent projects across software, operating systems, AI, networking, knowledge and creative tools. AWEONE is the ecosystem's shared entry point.

02

Websites vs repositories

A website is the experience a visitor uses. A GitHub repository contains project files, history, issues and contribution workflows. A website may be built from a repository, but the two are not identical.

03

Explore a project

Read the README, inspect the directory structure, find the entry point, identify dependencies and locate tests. Distinguish what exists today from future plans.

04

Your first web page

HTML describes structure, CSS controls appearance and JavaScript adds behavior. Try a small change, run it in the browser and observe the result.

05

Contribute responsibly

Use a feature branch, make a small focused change, test it, explain the change and open a pull request. Never commit credentials or personal secrets.

06

Test and troubleshoot

Reproduce the problem, read the first useful error, check the browser console, confirm configuration and test the actual user journey—not only whether a build command passes.

Learning principles

Be curious, test assumptions, respect privacy, document limitations, prefer small verifiable steps and treat security as a design requirement. A project is not “finished” merely because a page looks good: its core workflows, error handling, accessibility and deployment must also be tested.
