AWE / Security

Security is part of the product.

AWE projects should minimize exposed data, avoid secrets in static code and make security issues easy to report.

Static by default

Public pages should not contain private credentials or sensitive user data.

Least privilege

Integrations should request only the access they actually need.

Report issues

Use the relevant GitHub repository for security-related technical reports.
