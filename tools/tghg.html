Machine Learning

Մոդելը օրինակներից սովորում է պարամետրեր, որոնք օգնում են կատարել առաջադրանքը։

🧩

Transformer

Transformer-ը sequence-ի token-ների միջև հարաբերությունները մշակում է attention մեխանիզմով։

✨

Generative AI

Գեներատիվ համակարգերը կարող են ստեղծել տեքստ, կոդ, պատկեր, ձայն և այլ բովանդակություն։

🧠 Լեզվային մոդելի տեսողական շղթա

1 · Input — օգտատիրոջ տեքստը
2 · Tokenization — տեքստ → token-ներ → թվային ID-ներ
3 · Embedding — ID-ներ → վեկտորային ներկայացումներ
4 · Attention + Neural Network — token-ների հարաբերությունների մշակում
5 · Next-token prediction — հնարավոր հաջորդ token-ների գնահատում
6 · Decoding — token-ներ → վերջնական տեքստ
